# Raven Hub — Ventoy theme package

A dark-premium GRUB2 theme for Ventoy USB drives. Art, icons and fonts come
from the Elegant-grub2-themes project by vinceliuice et al. (GPL-3.0); this
package is generated by `build-ventoy.sh` from the Raven Hub source tree.

## What is in here

```
ventoy.json            theme-only config (drop-in for FRESH Ventoy USBs)
ventoy.json.example    richer example incl. an optional menu_class section
theme/raven-hub/       the theme itself (see its README.md)
```

## Install onto a Ventoy USB

1. Plug in the Ventoy USB and open its **data partition** (the big one with
   your ISO files).
2. **Fresh USB (no ventoy/ventoy.json yet):** copy `ventoy.json` and the whole
   `theme/` directory into the `ventoy` folder of the USB, so you get:
   `/ventoy/ventoy.json` and `/ventoy/theme/raven-hub/theme.txt`.
3. **USB that already has a ventoy.json:** do NOT overwrite it. Merge instead —
   from a checkout of this repository run:
   ```
   tools/ventoy-merge-theme.sh --existing /path-to-usb/ventoy/ventoy.json \
                               --theme ./ventoy.json
   ```
   The tool preserves every other plugin (control, menu_alias, persistence, …)
   and writes a merged file you can review before using.
4. Reboot and select the USB. `F5 → Check plugin json configuration` validates
   the JSON on the USB.

## If anything goes wrong (recovery)

* **Black screen or unreadable menu:** press `F7` (or `F5 Tools → Screen
  Display Mode → Force Text Mode`) to switch Ventoy to its text menu at any
  time — booting still works without the theme.
* **Wrong resolution:** `F5 Tools → Resolution Configuration`.
* **Theme not applied:** check `/ventoy/ventoy.json` paths with
  `F5 → Check plugin json configuration`.
* **Nuclear rollback:** delete the `theme/raven-hub*` folders and remove the
  `"theme"` object from `ventoy.json` (or restore the backup the merge tool
  made). Ventoy then shows its stock menu.

Full documentation: `VENTOY.md` in the Raven Hub repository.
